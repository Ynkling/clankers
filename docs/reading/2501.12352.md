## 1. What the paper actually does

### 1.1 The claim in one paragraph
A theory/unification paper (two small experiments, no new SOTA model). It formalizes associative recall as two steps — *memorization* and *retrieval* — and shows that memorization "can be implemented by solving a weighted regression problem" over the in-context key-value pairs, at test time, inside the forward pass. Every popular sequence layer is then "a mathematical consequence of choosing (1) the regression weights, (2) the regressor parameterization, and (3) the optimization algorithm" (p.2). Linear attention, gated linear attention/SSMs, DeltaNet/fast weights, online learners (Longhorn, Gated DeltaNet, Titans), TTT, and softmax attention are all derived as instances. Two by-products: (i) linear attention is a crude least-squares solver that drops the inverse key covariance (K_tᵀK_t)^{−1}, which explains both its weaker recall and its output-norm instability; (ii) softmax attention with QK-normalization is exactly Nadaraya–Watson local-constant regression, which "offers a mathematical justification for the empirical effectiveness of query-key normalization" (abstract). It proposes (but does not train) a "higher-order" attention from local *linear* regression (p = 1). Section 6 shows that for MQAR a single memory layer plus one length-2 short convolution on the keys suffices, that "memory capacity, not sequence length, limits model performance", and that exact recursive least squares (RLS) beats linear attention when the number of pairs exceeds the key dimension.

### 1.2 The core objects (copied in the paper's notation)

Associative memory = a function m : R^{D_k} → R^{D_v} with m(k_i) ≈ v_i (Kohonen 1972, 1989) — a "hetero-associative memory" (p.6).

**Memorize associations (Eq. 8, p.6):**

    m_t ≈ argmin_{m ∈ M} (1/2) Σ_{i=1}^{t} γ_i^{(t)} ‖v_i − m(k_i)‖₂²

"where the importance of each association is controlled by adjusting the relative weights {γ_i^{(t)}}_{i=1}^t … here we allow M to be any function class. We refer to this relationship between regression and associative memory as the 'regression-memory correspondence'." (p.6)

**Memory retrieval (Eq. 9, p.7):**

    y_t = m_t(q_t)

"When Equation 8 attains zero-loss, m_t memorizes all associations perfectly, and we get perfect retrieval: m_t(k_i) = v_i for i = 1, …, t. For certain function classes M, e.g. smooth functions, m can also extrapolate outside of the existing set of keys. In those cases, m_t(q) instead retrieves a value based on the proximity of q to the existing set of keys." (p.7)

Multihead: "multihead test-time regression can be implemented using H independent sets of queries, keys, and values, resulting in H independent associative memory maps at each timestep." (p.7)

The recipe (p.7): choose "1. the relative importance of each association, specified through weights in Equation 8, 2. the function class M over which we search, 3. the minimization algorithm".

Notation: K_t = [k_1 … k_t]ᵀ ∈ R^{t×D_k}, V_t = [v_1 … v_t]ᵀ ∈ R^{t×D_v}; Γ_t = diag(γ_i^{(t)}).

### 1.4 Stability bound (Eq. 13, p.9; derivation Appendix A, p.31)

    ‖y_t‖₂ = ‖V_tᵀK_t(K_tᵀK_t)^{−1}q_t‖₂ ≤ ‖q_t‖₂ Σ_{i=1}^t ‖v_i‖₂‖k_i‖₂ / λ_min(K_tᵀK_t)

"When we ignore the covariance matrix, approximating it with the identity, the denominator disappears and the output y_t can grow arbitrarily large with the sequence length, leading to training instability. This instability indeed shows up in practice for linear attention, and Qin et al. (2022) proposed output normalization to stabilize training. Our derivation shows that output normalization works by approximately restoring the self-normalizing property of Equation 11 that linear attention loses." (p.9)

### 1.5 Experiments and training details (everything the paper gives)

**Section 5 — online regression with no learnable parameters (pp.17–18).** Keys from a switching AR process, Eq. 55: k_{t+1} = 0.9k_t + 0.02ε_t for t < T/4; 0.999k_t + 0.02ε_t for t ≥ T/4; D_k = 64, T = 256; ε_t ~ N(0, Σ) with "unit diagonals and non-zero off-diagonals" so that K_tᵀK_t ≠ I; v_t = k_{t+1}/‖k_{t+1}‖₂; q_t = k_{t+1} (one-step-ahead forecast). Layers: linear attention (Eq. 2, with Qin et al. 2022 output normalization — footnote 2, p.18), unweighted RLS (Eq. 11), softmax attention (Eq. 1), p = 1 local-linear attention (Eq. 52), naive "use v_{t−1}" baseline. Result (Figure 2, qualitative only — no numbers in text): "unweighted recursive least squares is unable to adapt to this change since it cannot discount datapoints from before the transition; as a result, it maintains a high error throughout the latter timesteps. In contrast, the nonparametric regressors are able to adapt quickly to the transition since earlier keys are dissimilar to the later keys. Interestingly, increasing our nonparametric softmax regressor from p = 0 to p = 1 allows the model to better adapt to both the initial fast-changing period and the sudden regime change. As expected, linear attention performs the worst since K_tᵀK_t ≠ I in our dynamical system" (p.18).

**Section 6 — MQAR (pp.19–20).** Task: P "unique and consistent cue-response tokens {(u_j, v_j)}_{j∈[P]} with each cue u_j mapping one-to-one to its response v_j"; sequence (u_{i_1}, v_{i_1}, …, u_{i_{T/2}}, v_{i_{T/2}}, u_{i_j}); predict v_{i_j}. Construction: keys by short convolution k_t = w_0x_t + w_1x_{t−1} = x_{t−1} (w_0 = 0, w_1 = 1), q_t = v_t = x_t; memory stores {(x_{t−1}, x_t)}; with linear attention, Eq. 58: y_{T+1} = m_{T+1}(u_{i_j}) = (Σ_{t=1}^{T+1} v_tk_tᵀ)u_{i_j} = Σ_t x_tx_{t−1}ᵀu_{i_j}; with orthonormal token embeddings "x_{t−1}ᵀu_{i_j} is nonzero only when x_{t−1} = u_{i_j} … Since the cue-response map is one-to-one, the remaining tokens are all v_{i_j}, producing the output y_{T+1} ∝ v_{i_j}". Trained version: "We train on the MQAR task following the procedure of (Arora et al., 2023a). However, we use only one test-time regression layer and one length-2 convolution (for constructing the keys) … We also remove the typical MLP block following the sequence layer … We fix our key dimensions D_k to be the same as the embedding size, d_model = 64. We compare two test-time regression architectures, linear attention and unweighted recursive least squares (RLS) of Equation 11. We do not use gated variants of linear attention since this task does not require any forgetting" (p.20). **No learning rate, optimizer, initialization, step count or seed information is given anywhere in the paper.** Results (Figure 3, qualitative in text): "In the case where d_model = P = 64, linear attention solves MQAR perfectly, independent of sequence length as predicted. Once the number of keys increases to P = 128, linear attention can no longer perfectly solve MQAR, since it is impossible for 128 keys to be orthogonal in a d_model = 64 dimensional space. In contrast, an unweighted RLS layer (Equation 11) improves upon linear attention by accounting for the key covariance matrices {K_tᵀK_t}, allowing it to better test-time memorize the cue-response map, even when P > d_model. As a result, RLS is able to solve MQAR regardless of the sequence length." (p.20). No accuracy numbers for the P = 128 RLS case are in the text; "solve" is the paper's word. [inference: a linear map in 64 dimensions cannot store 128 arbitrary independent associations exactly, so "solve" here must mean the readout argmax is right, not zero regression loss.]

No other training details, ablations, or large-scale results exist in this paper.

## 2. Verbatim quotes that matter (with page)

Framing
- "Our crucial observation is that we can implement the memorization step by solving a weighted regression problem." (p.2)
- "Our terminology reflects that the regressor is regenerated with each forward pass and depends only on the input tokens rather than a fixed training dataset." (p.2)
- "an AR-based sequence layer is a mathematical consequence of choosing (1) the regression weights, (2) the regressor parameterization, and (3) the optimization algorithm for finding the regressor." (p.2)

Linear attention as crude least squares; capacity and orthogonality
- "Since the recurrent state M_t of linear attention has finite size (D_v × D_k numbers), M_t can only store a bounded amount of information. In Equation 2, M_t weighs all key value pairs equally across timesteps, trying to compress all key-value pairs equally well into its finite-sized state." (p.5)
- "One crude but hardware-efficient simplification would be to assume that K_tᵀK_t = I, avoiding matrix inversion completely, at the cost of some recall ability." (p.8)
- "Thus linear attention is a crude associative memory that ignores the covariance between the dimensions of the key vectors. In fact, it is an optimal linear memory only when t ≤ D_k and the keys are orthonormal k_iᵀk_j = δ_ij." (p.8)
- "Each rank-1 outer product v_tk_tᵀ can be thought of as writing a new key-value pair into memory." (p.4)
- "Memory capacity, not sequence length, limits model performance." (heading, p.19) "once the memory is large enough, the difficulty of MQAR is independent of the sequence length T, which may be counter to the intuitive notion of longer sequences being more difficult. Instead, models are limited by their ability to fully memorize all P key-value pairs." (p.20)
- "Although our construction in Equation 58 relied on the embedding space being large enough to allow orthonormality, trained models can still succeed without perfectly orthonormal embeddings, which we empirically show in Figure 3." (p.20)

Delta rule semantics
- "An alternative to attenuating all past information in M_{t−1} is to forget only the values whose keys are most similar to the new key k_t. This was the motivation behind DeltaNet" (p.5)
- "we can interpret the update rule as rewriting the value that was bound to key k_t. The update rule deletes an old value v_t^old = M_{t−1}k_t retrieved from the previous timestep's memory M_{t−1} but using the new key k_t. The layer then updates the recurrent state with a new interpolated value v_t^new, binding it to k_t." (p.5)
- "Equation 29 is known by many names, such as the delta rule or the Widrow-Hoff algorithm (Widrow and Hoff, 1988). Within the adaptive filtering literature this recurrence is known as Least-Mean Squares (LMS) (Haykin, 2014) … the prevalence of the update across disciplines comes from the fact that the update rule is actually an SGD update." (p.13)
- "The stochastic gradient approach to streaming inputs has the advantage that m_t focuses more on recent key-value pairs, rather than uniformly over all timesteps as in the case of unweighted RLS and unweighted linear attention." (p.12)
- "The sequential form is known as online linear regression or recursive least squares (RLS) (Haykin, 2014). Thus during training we can parallelize across the sequence axis by solving a batch of T linear systems, and during testing we can unroll the recurrence into a recurrent neural network." (p.9)

Forgetting / weights
- "For many kinds of sequential data, such as time-series data and text data, recent tokens are more informative of predicting the next token. Thus a natural requirement is to encourage our memory m_t to focus more on the recent history by downweighting the past." (p.9)
- "The underdetermined case has the same solution in both the weighted and unweighted case; intuitively this is because when the system is underdetermined, there are infinitely many solutions that interpolate the data points and attain zero regression loss, rendering the weights irrelevant." (p.10)
- "Our derivation of gating from weighted least squares provides a mathematical grounding for the forgetting heuristic upon which these sequence layers were based." (p.10)
- "Notably, the first term of our new recurrence resembles Equation 27 but also includes a multiplicative factor similar to a forget gate." (p.14, on L2 regularization)
- "Past works have shown that decoupling weight decay from the step size results in better generalization and easier-to-tune hyperparameters (Loshchilov and Hutter, 2019), suggesting that similar modifications to Gated DeltaNet may improve model performance." (p.14)
- "When δ_t = 0, we see that M_t = M_{t−1} and the latest association is excluded completely." (p.13, Longhorn)
- "The regression problem is stationary (the cue-response map doesn't change over time), hence no forgetting mechanism is needed to solve the task." (Fig. 3 caption, p.20)
- "without decaying weights, linear attention and unweighted RLS are unable to adjust to the resulting non-stationary data." (Fig. 2 caption, p.18)

Optimizer / preconditioning
- "Exploring other preconditioners, e.g. quasi-Newton methods, that interpolates between the two extremes may be an interesting direction for future research." (p.12)

## 3. Relevance to the BDH-CQ reconstruction

### 3.1 What matches Pathway's wording, and what does not
Pathway: S_t = U_θ(S_{t−1}, D_t), "linear attention being the conceptually simplest standalone realization of linear correction rules on S, capturing the special case S_t = S_{t−1} + U_θ(D_t)".

- **The special case matches exactly.** The paper's Eq. 2/24 is S_t = S_{t−1} + v_tk_tᵀ: the update does not read S_{t−1}; it is "one-step of full batch gradient descent on the least square objective" from the origin (p.12). So in the paper's taxonomy Pathway's special case = "no error term, no preconditioning".
- **"Linear correction rule" has no verbatim counterpart.** The words "correction", "correct", "error-correcting" do not occur anywhere in the paper (checked over the whole text). The paper's vocabulary for the same object is: "delta rule", "Widrow-Hoff", "LMS / NLMS / Leaky LMS", "SGD update", "rewriting the value that was bound to key k_t", "deletes an old value", "projection method", "Kaczmarz's method", "online linear regression or recursive least squares (RLS)" (p.9), "streaming least-squares" (Vignette 3 title, p.11), "online learning layers / online learners" (p.6), "online regression" (Section 5). It never says "online least squares"; "recursive least squares" appears on pp.9, 10, 17, 18, 20. **[inference]** The natural reading of "correction" in this paper's terms is the residual (v_t − S_{t−1}k_t): the rule corrects the memory by the prediction error on the new datum. That is the delta/LMS family (Vignette 3), not Hebbian accumulation.
- **The latent loop H_0 = E(x*, S_K), H_{r+1} = F(H_r, S_K), ŷ = G(H_R) has no counterpart.** Retrieval in this paper is one function application, y_t = m_t(q_t) (Eq. 9). The only iterative objects are (a) I iterations of GD on the *memory* (Eqs. 20–23, 26–28), which iterate S, not a latent H; and (b) for the higher-order (p ≥ 1) local regressor, retrieval itself becomes a per-query optimization ("we need to jointly solve for all of (M[0], …, M[p]) to get the retrieved value M[0]", p.16) — which one *could* run iteratively with the memory held fixed. **[inference]** That is the closest structural analogue in this paper to "iterate a latent state against a fixed S_K": retrieval as solving a regression problem given the memory rather than as a single read. Iterative Hopfield-style retrieval (Ramsauer et al. 2021; Krotov & Hopfield; Millidge et al. 2022) is cited in Related Works (p.21) but not developed.

### 3.2 Which members of the family are "linear in S" — S_t = A_t S_{t−1} + B_t with A_t, B_t from the current input only

The paper does not use this classification; the following is read off its equations **[inference]**. Note the paper's convention puts the key-dependent matrix on the *right* of M (M_{t−1}(I − βkkᵀ)), i.e. S_t = S_{t−1}A_t + B_t; this is still affine in S.

Linear (affine) in S with input-only coefficients:
1. Linear attention (Eq. 2): A_t = I, B_t = v_tk_tᵀ. Feature-mapped variants (Eq. 3): B_t = v_tφ(k_t)ᵀ.
2. Gated LA / RetNet / GLA / Mamba-2 / mLSTM / RWKV-6 / GateLoop / LRU / HGRN (Eq. 4/16): A_t = γ_tI (scalar or, in the cited models, diagonal/per-channel), B_t = v_tk_tᵀ.
3. DeltaNet (Eq. 29): A_t = I − β_tk_tk_tᵀ (a scaled Householder-like matrix), B_t = β_tv_tk_tᵀ.
4. Longhorn (Eq. 31): same with β_t = δ_t/(1 + δ_t‖k_t‖²).
5. NLMS/Kaczmarz (Eq. 33): same with β_t = 1/‖k_t‖².
6. Leaky LMS = Gated DeltaNet (Eq. 37/41): A_t = α_t(I − η_tk_tk_tᵀ), B_t = η_tv'_tk_tᵀ.
7. DeltaProduct (multiple SGD steps on the same (k_t, v_t), p.13): A_t = product of several (I − β^{(i)}k_tk_tᵀ) factors; still affine in S_{t−1}.
8. Batch GD with I steps restarted from 0 every token (Eqs. 20–23): not a recurrence in S at all (A_t = 0 effectively; recomputed from the whole prefix).
9. Titans-LMM with a *linear* memory [not in the paper]: with momentum the joint state (M, S_momentum) is affine in itself, so "linear in the joint state"; Titans as published uses an MLP memory → nonlinear.

Not linear in S alone:
10. Exact (weighted) RLS, Eq. 11/15. The paper only says the inverses can be propagated "via the Woodbury matrix identity" (p.9). **[reconstruction, standard RLS, not in paper]** with P_t ≜ (K_tᵀΓ_tK_t)^{−1} and forgetting factor γ_t: P_t = (1/γ_t)[P_{t−1} − P_{t−1}k_tk_tᵀP_{t−1}/(γ_t + k_tᵀP_{t−1}k_t)], M_t = M_{t−1} + (v_t − M_{t−1}k_t)k_tᵀP_t. The M-update is affine in M_{t−1} *given P_t*, but P_t is a second state whose update is rational in P_{t−1}; so the full state (M, P) is not of the required form. RLS = the delta rule with the scalar step β_t replaced by the matrix preconditioner P_t.
11. TTT with nonlinear m_t (MLP) — the gradient is nonlinear in the parameters.
12. Softmax attention and kernel regression (nonparametric: the "state" is the whole K_t, V_t; retrieval Eq. 50 is a nonlinear normalized average).
13. Higher-order (p ≥ 1) local regression — nonparametric, with a per-query matrix inverse.

**[inference for the reconstruction]** If Pathway's phrase "linear correction rules on S" is taken literally (U_θ linear in S, with coefficients that are functions of D_t), the admissible set is exactly rows 1–7 above: Hebbian ⊂ gated Hebbian ⊂ delta/LMS ⊂ Longhorn/NLMS ⊂ Leaky-LMS = Gated DeltaNet ⊂ DeltaProduct. The paper gives a one-parameter-family argument for preferring the gated-delta end: every step from left to right either (a) adds the error term (v − Sk), which the paper shows is a true SGD step on the least-squares objective and which "deletes an old value … binding it to k_t", or (b) adds decay/L2, which it shows is Leaky LMS. Full RLS would require Pathway to carry a second (D×D) covariance state; nothing in the brief's quotes suggests that, and the paper itself says the inversion "is not efficient on matrix-multiplication based hardware" (p.10).

### 3.3 What "beyond the delta rule" could mean, per this paper
The paper's own list of levers for a better test-time regressor:
1. **Preconditioning / second order.** "The difference in performance comes from whether the optimizer accounts for the curvature of the objective, governed by the covariance of the keys … Exploring other preconditioners, e.g. quasi-Newton methods, that interpolates between the two extremes may be an interesting direction" (p.12). The extremes are Hebbian (no preconditioner) and RLS (exact inverse covariance). A diagonal or low-rank preconditioner would keep the rule "linear in S" with a cheap extra state. [inference]
2. **Adaptive/normalized step size.** Longhorn's β_t = δ_t/(1 + δ_t‖k_t‖²) (Eq. 31), and the unexplored hyperparameter-free NLMS β_t = 1/‖k_t‖² (Eq. 33), which enforces the hard constraint M_tk_t = v_t (Eq. 32).
3. **Decoupled weight decay.** Gated DeltaNet couples λ_t to β_t; AdamW-style decoupling "may improve model performance" (p.14).
4. **Momentum** (Titans) and "more effective, stable, and parallelizable test-time optimizers" (p.22).
5. **Multiple steps per token** (DeltaProduct, p.13).
6. **Nonlinear memories** (TTT-MLP): "the space of nonlinear neural regression models remains largely unexplored" (p.21).
7. **Output normalization / self-normalization** (Eq. 13): a Hebbian memory needs output normalization because it lost the 1/λ_min(KᵀK) factor.

## 4. Relevance to distant context cues

**What carries context across distance in this paper, and how far.**
1. The *memory itself* is the only long-range carrier. Its horizon is set by the weights: γ_i^{(t)} = Π_{j=i+1}^t γ_j (gated; data-dependent if γ_t = γ(x_t)), uniform (RLS/linear attention, horizon = whole prefix), or implicit recency from SGD (delta rule). The paper does not propose any separate "context channel".
2. The *short convolution on keys*, Eq. 56 (p.18): k_t = Σ_{i=0}^{K−1} w_iW_Kx_{t−i}. Time scale: K tokens (K = 2 in their MQAR solution). Context here is **inferred from the data** (the neighbouring token is folded into the key); there are no labels, task ids or boundary markers. Training: the filter w_i and W_K are ordinary slow weights trained end-to-end by the task loss (the only trained model in the paper; no further details).
3. **Query-dependent weights** (softmax, Eq. 48): γ_i^{(t)} = s(k_i, q). This is what let the nonparametric regressors handle the regime switch in Section 5: "earlier keys are dissimilar to the later keys" (p.18). Context selection happens at *retrieval* through key similarity — which only works if context is already *in the keys*.

**What the paper says about multi-layer look-back.** It attributes long-range copying in Transformers to induction heads in early layers and says a short conv frees "the earlier self-attention layers from having to learn the induction head behavior (Xu et al., 2024)" (p.19). **[inference]** Read in reverse, this is exactly our per-layer-residual-gate hypothesis: without a convolution wide enough to reach the cue, a *previous layer's memory* must perform the look-back and deposit the cue into each position's representation; the next layer's keys/gate then see it locally. The paper offers no experiment on this.

**What the paper says about stationarity vs. distance.** For a *stationary* cue-response map, distance is irrelevant: "once the memory is large enough, the difficulty of MQAR is independent of the sequence length T" (p.20). For a *non-stationary* map, distance matters only through forgetting (Section 5). **[inference]** Our header layout is, from the point of view of a single memory with keys = KEY tokens, a non-stationary map (the same KEY has different VAL in different blocks) — but the queries at the end need *all* regimes, so forgetting cannot be the fix; the fix must be to make the map stationary again by putting the stream into the key (or, equivalently, into the channel). The paper's framework locates the whole difficulty in "constructing effective key-value pairs" (Section 6 title), not in the memory. That is the paper's main message for the distant-cue problem: it is a key-construction (= gate-input) problem.

## 5. Relevance to our gate

### 5.1 Our k-channel memory in this paper's language [inference, but exact algebra]
Our score (x_t·x_s)(g_t·g_s)·decay^{t−s} equals φ(x_t)ᵀφ(x_s)·γ_s^{(t)} with the feature map

    φ(x_s) = x_s ⊗ g_s  (Kronecker product; dimension D·k),   γ_s^{(t)} = decay^{t−s}.

So the multi-channel memory *is* the paper's "feature-mapped linear attention with geometric weights" (Eq. 3 + Eq. 16), with a learned, context-dependent, degree-2 feature map (content × channel), implemented by the one-step batch-GD (Hebbian, K_tᵀΓ_tK_t ≈ I) solver. Three consequences follow directly from the paper's Vignettes:
- It is "optimal … only when t ≤ D_k and the keys are orthonormal" (p.8) — in our terms, when the stored vectors x_s ⊗ g_s are orthonormal. For BindTask that means keys orthogonal within a channel **and g's for different streams orthogonal**, i.e. one-hot and disjoint: exactly the oracle gate. Soft/overlapping g's interfere by an amount proportional to g_s·g_{s'}: this is the *mechanism* behind our "merge" pathology, in the paper's words "a crude associative memory that ignores the covariance" between the stored features.
- The exact least-squares memory over the same features would need only *linear independence* of the stored x⊗g vectors, not orthogonality, to recall exactly — the inverse covariance (Φ_tᵀΓ_tΦ_t)^{−1} "subtracts" the cross-talk. [inference] This means an RLS-type or delta-type update would make the gate's job strictly easier (it would not need perfectly disjoint channels). See 5.3.
- Multihead attention (p.7) is the special case of our model where g is a fixed, token-independent one-hot per head and every token writes to every head. Our gate makes the head assignment data-dependent. The paper has no such routed-head construction.

### 5.2 Same key, different values in different contexts (our conflicting-bindings problem)
The paper never discusses key collisions, "conflicts", or a d² limit by those names. What it does say:
- The memory is a *function* of the key: zero loss means "m_t(k_i) = v_i for i = 1, …, t" (p.7). **[inference]** Two associations with identical keys and different values make zero loss impossible for any function class; the framework itself therefore says the only resolutions are (a) change the keys so they differ (context in the key: Section 6's short conv, or our x⊗g feature), or (b) change the weights γ so one binding dominates (forgetting / query-dependent weights), or (c) accept the compromise the optimizer produces.
- What each optimizer does with a true collision **[inference from the paper's equations]**: exact (weighted) least squares, when the colliding key k is linearly independent of the other keys, returns the γ-weighted *mean* of the colliding values at k (the residuals at k decouple from the rest); softmax/local-constant regression returns exactly the normalized weighted average Eq. 50; Hebbian linear attention returns the unnormalized weighted *sum* Σγ_jv_j‖k‖² plus cross-talk; the delta rule with β_t = 1 (or NLMS) returns the *last-written* value exactly — "rewriting the value that was bound to key k_t" (p.5) — and intermediate β interpolates (v^new = βv + (1−β)v^old, Eq. 5). So: least squares averages, Hebbian sums, delta overwrites. None of these solves our task alone, because the task needs *all* S values retrievable; only context-dependent keys/features do.
- Capacity / orthogonality statements (all quoted in §2): bounded state (p.5); optimal only for t ≤ D_k orthonormal keys (p.8); "impossible for 128 keys to be orthogonal in a d_model = 64 dimensional space" (p.20); "Memory capacity, not sequence length, limits model performance" (p.19). Note the paper's capacity unit is the key dimension D_k (number of linearly independent keys), not D_v·D_k: the state has D_v × D_k numbers but exact storage is limited to D_k independent keys per memory. **[inference]** For us: per channel at most N linearly independent (content) keys; across k one-hot channels, N·k (key, stream) pairs — the "d² limit" in our vocabulary corresponds to the paper's D_k-independent-keys limit applied to the D·k-dimensional feature x⊗g.
- Mechanisms by which context selects which regressor is used: the paper has exactly two — **query-dependent weights** γ_i^{(t)} = s(k_i, q) (softmax = locally weighted regression in key space), and **time-dependent weights** (forgetting). It has **no** mixtures, gating networks, or "kernels on context" — the word "mixture" does not occur. **[inference]** Our gate is precisely the missing third option: weights γ_s^{(t)} = (g_t·g_s)·decay^{t−s} — a finite-rank kernel on an inferred context variable, which is what keeps the layer recurrent (the same trick that makes linear attention linear). This is a clean way to describe the gate in a write-up: "locally weighted test-time regression where locality is measured in a learned k-dimensional context space, with a rank-k kernel so that the weighted sums remain a recurrence".
- The paper's two "additive" alternatives would *not* solve the grouped task **[inference, my algebra]**: a short conv that *adds* the context token into the key, k_t = aKEY_i + bCTX_s, gives, with orthonormal embeddings and a Hebbian memory, score a²δ_{iq} + b²δ_{sq}: the correct value scores a² + b² but every same-key-wrong-stream value scores a² and every same-stream-wrong-key value scores b², and a distractor value token that appears in both lists ties with the target. Exact least squares over the additive features fits an additive model v ≈ A·KEY + B·CTX, which cannot represent an interaction v_{i,s}. So the function class must contain key × context *products* — the paper's "polynomial feature maps" (Poggio 1975; Based/ReBased, p.9) — and our channels are a learned low-rank (k ≤ S) version of exactly that product. This is support for the channel architecture being necessary, not just convenient.

### 5.3 Concrete ideas for the memory and the gate (equations, init, training), with what the paper supports or warns

**A. Replace the Hebbian write by a delta-rule (or NLMS) write inside each channel.** In our notation, with feature φ_t = x_t ⊗ g_t (or per channel c: write weight g_{t,c}):

    M_t = M_{t−1}(γ I − β_t φ_t φ_tᵀ) + β_t v_t φ_tᵀ      (Eq. 29 with decay; Gated-DeltaNet form Eq. 41)
    NLMS choice (Eq. 33): β_t = 1/‖φ_t‖₂²  — hyperparameter-free; enforces M_t φ_t = v_t exactly.

Paper support: the delta rule is the SGD step on the *same* objective our Hebbian write crudely solves (p.12–13); it "forget[s] only the values whose keys are most similar to the new key" (p.5); NLMS "has not been explored as a sequence layer" (p.13). Pitfall: Gated DeltaNet's decay and step are coupled; the paper recommends decoupling (p.14), i.e. keep our decay γ as a separate parameter from β_t. **[inference]** Expected effect for us: exact recall of the most recently written (key, channel) binding regardless of channel overlap, and residual cross-talk that scales with the overlap g_s·g_{s'} rather than accumulating; the gate then only needs *linearly independent* channel codes, a weaker requirement than disjoint ones.

**B. A "header register" channel for the header layout.** Combine a per-token *write gate* β_t (Longhorn's δ_t: "When δ_t = 0 … the latest association is excluded completely", p.13) with the delta rule's overwrite semantics: a channel whose key is a constant feature (a bias dimension) and whose value is the current token, written with β_t ≈ 1 only at CTX tokens and β_t ≈ 0 elsewhere, holds exactly the most recent header and is read at every position by the constant key. **[inference]** This is a one-channel implementation of "copy the block header into every position", which is what layer 1 must do in our per-layer-residual-gate plan; the delta rule is essential here because a Hebbian register would accumulate all headers (sum), while the delta rule replaces. The paper's Section 5 is the evidence that replacement/forgetting is what handles regime switches.

**C. Short convolution on the memory's keys, not only on the gate input.** Eq. 56: k_t = Σ_{i=0}^{K−1} w_iW_Kx_{t−i}. The paper's MQAR solution uses k_t = x_{t−1} (w_0 = 0, w_1 = 1), q_t = v_t = x_t — i.e. the key at a VAL position is the preceding KEY token. Our BindTask writes at VAL with the key at t−1 and the stream at t−2, so a width-3 conv on *keys* (not just on the gate) makes CTX available in the key — but, per 5.2, additively, which is insufficient for the Hebbian memory; it becomes sufficient only together with a product feature (our channel) or a preconditioned solver. Paper support for making the gate see neighbours: "removing the short convolution results in severe performance drops" (p.19) — our window gate is this idea applied to the routing variable. The paper gives no filter initialization; its construction suggests initializing so that the previous-token tap is dominant.

**D. Forget gate per channel.** The paper's grounding: a data-dependent γ_t is weighted least squares with γ_i^{(t)} = Π_j γ_j (Eq. 14); implementation choices are deferred to "Table 1 of Yang et al. (2024b)" (p.5); L2 regularization gives a decay (1 − β_tλ_t) (Eq. 37). Two warnings: (i) in the *underdetermined* regime the exact solution ignores the weights entirely (p.10) — for an exact or near-exact solver, a forget gate only acts once the memory is full; for the Hebbian solver it always acts; (ii) forgetting is irrelevant for stationary recall tasks (Fig. 3 caption) and harmful if the forgotten items are queried later — so for BindTask-style tasks with end-of-sequence queries, a forget gate should learn to stay open, and the paper offers no evidence that a learned γ can be discovered from loss alone (its MQAR experiment deliberately omits gating).

**E. Normalization.** The bound Eq. 13 says Hebbian outputs grow with t unless normalized; "output normalization (Qin et al., 2022) … restores the self-normalizing property" (p.9, Appendix A). Our LayerNorm after attention is this fix; the paper supports keeping it. For a softmax-free memory, QK-norm (unit-norm keys/queries, Eq. 51) is the paper's recommended way to make similarity a proper distance — for us, normalizing x_t (and g_t is already on the simplex) would make (x_t·x_s)(g_t·g_s) a bounded kernel.

**F. What the paper supports / contradicts about our beliefs.**
- Supports: single-channel Hebbian fails on conflicting bindings (crude memory, sums); oracle partition works (orthonormal features); window gate = short conv idea; LayerNorm after attention; the problem for header layout is key/gate *construction*, not memory horizon.
- Contradicts/complicates: "distance" is not the paper's difficulty axis — capacity and non-stationarity are; our P = 8 oracle-gate failure within 24k updates is therefore unlikely to be a memory-capacity issue (N = 256 ≫ P·S) and more likely an optimization/readout issue — the paper offers nothing on optimization dynamics, so this is only a pointer.
- Pitfalls named: output-norm blow-up (Eq. 13); unnormalized softmax instability (p.15); coupled decay/step in Gated DeltaNet (p.14); capacity cliff at P > D_k for linear attention (p.20); forgetting irrelevant when the system is underdetermined (p.10). The paper says nothing about router collapse, straight-through estimators, or pooled summaries.

### 5.4 Query-time construction: why keys should include neighbours
Everything the paper says is in Section 6 (quoted in §2): the short conv "imitates the induction heads behavior", lets layers "look back", and "allows the sequence layer to memorize and retrieve bigram-like key-value pairs". The only mechanism-level argument is the MQAR construction: the association the task needs is (previous token → current token), so the key *must* be the previous token; a per-position linear projection cannot express that, a length-2 conv can. There is a typo in the text: "Setting w_0 = i and w_j = 0 for j ≠ 0 in Equation 56 enables other sequence layers to also 'look back' at the token from timestep i" (p.19) — **[reconstruction]** intended: w_i = 1 and w_j = 0 for j ≠ i (a pure shift by i). It cites Xu et al. 2024 "KV Shifting Attention" (arXiv 2411.19574) for the Transformer version. QK-norm is derived for softmax only (Eq. 51); the paper does not discuss normalizing keys in linear/Hebbian memories except via output normalization.

### 5.5 Multi-timescale, multiple memories, choosing the recency weights
- No multi-timescale memory is proposed. The only "multiple memories" are multihead (independent maps, p.7).
- Decay is never tuned or learned in the paper; it is a design choice ("γ_j ∈ [0,1]") whose only justification is "recent tokens are more informative" (p.9). The literature pointer for choosing it is adaptive filtering: Haykin 2014 and Johnstone et al. 1982 ("Exponential convergence of recursive least squares with exponential forgetting factor") — [from that literature, not the paper: effective memory ≈ 1/(1 − γ)].
- Three different sources of recency are distinguished: explicit γ (gating), implicit recency of SGD (delta rule, p.12), and query-locality (softmax, p.18). Our decay 0.95 is of the first kind; a delta-rule write would add the second kind for free.
- The authors' own earlier work "Sequence modeling with multiresolution convolutional memory" (Shi, Wang, Fox, ICML 2023) is cited as outside scope (p.21) — relevant to multi-scale memory but not discussed.

## 6. Loose threads

Paper-internal
1. **NLMS/Kaczmarz layer (Eq. 33)** — explicitly flagged as unexplored; hyperparameter-free; enforces M_tk_t = v_t. Directly implementable in our channels.
2. **Quasi-Newton / partial preconditioning** between Hebbian and RLS (p.12) — open direction; a diagonal preconditioner (per-feature running second moment, Adagrad-style) would keep the rule linear in S with O(D·k) extra state. [inference]
3. **Decoupled weight decay for Gated DeltaNet** (p.14) — a one-line change.
4. **Underdetermined regime makes weights irrelevant** (p.10) — matters when comparing forget gates across solvers.
5. **Higher-order attention (p = 1)** — derived, used in Section 5, never trained; impractical costs (p.17); "offset softmax" form Eq. 54.
6. **Eq. 13 / Appendix A** — the self-normalizing bound; the only appendix.
7. **Figures 2 and 3** carry the only empirical results and their numbers are not in the text; the P = 128 RLS claim ("solve MQAR regardless of the sequence length") is not quantified.
8. **Garbles in the extraction** (not the paper's fault): Eq. 30's prose "ℓ_t(M) = δ‖v_t − Mk_t‖₂²/" should read δ_t‖v_t − Mk_t‖₂²/2; Eq. 34's regularizer index is written λ_i inside Σ_i but used as λ_t afterwards; Figure 1's taxonomy is a flattened layout (the table in §1.3 restores it); the "w_0 = i" typo (§5.4) is in the paper itself.
9. The paper is agnostic about **how the slow weights (W_Q, W_K, W_V, gates, conv filters) are trained** — "The traditional 'slow-weights' can be seen as the weights of a metalearner" (p.5). Nothing on learning rates, initialization, or the dynamics by which a routing/gating variable could be discovered — i.e. nothing on our central question.

## 7. Verdict

This paper gives us a vocabulary and two concrete levers, not an answer. The vocabulary: our k-channel BDH memory is feature-mapped, geometrically-weighted linear attention with the feature φ(x) = x ⊗ g — a learned degree-2 (content × context) feature — solved by the crude one-step Hebbian solver; the oracle gate is the orthonormal-features case where that crude solver is exact, and channel merging is the paper's "ignores the covariance" failure. The levers: (1) replace the Hebbian write by a delta/NLMS write per channel (Eq. 29/33; Eq. 41 with decoupled decay), which should relax the gate's requirement from disjoint channels to linearly independent channel codes and which gives a natural "header register" (overwrite-on-CTX) for the header layout; (2) treat the distant-cue problem as a key-construction problem — the paper's whole Section 6 — which supports the per-layer residual gate (a previous layer's memory does the look-back that a width-3 conv cannot). On BDH-CQ, the paper settles the vocabulary question negatively: "correction" never appears, but everything in Pathway's description maps onto the paper's Vignette 3 family (delta/LMS → Leaky LMS = Gated DeltaNet → Longhorn/NLMS), all of which are affine in S with input-only coefficients, whereas exact RLS needs a second covariance state and the latent loop H_{r+1} = F(H_r, S_K) has no counterpart here beyond "retrieval as solving a local regression". The paper says nothing about how a routing variable can be *discovered* from the loss, about collapse, or about training recipes, so it does not move our main open question. Confidence: high on the equations and classification (they are copied/derived directly), medium on the practical benefit of the delta-rule write for the gate (the paper's evidence is MQAR at P > D_k with exact RLS, not a routed-memory experiment), and the Memory Mosaics / Bietti pointers are from my memory and need checking.
