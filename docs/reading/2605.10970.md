# arXiv 2605.10970v1 — "Context-Gated Associative Retrieval: From Theory to Transformers"

**Authors:** Moulik Choraria (UIUC, corresponding, moulikc2@illinois.edu), Argyrios Gerogiannis (UIUC), Vidhata Jayaraman (UIUC), Ankur Mani (U. Minnesota, Twin Cities), Lav R. Varshney (Stony Brook). First two: equal contribution. Acknowledges "Dmitry Krotov for early discussions on modeling context-based retrieval" (p.10). Submitted 8 May 2026, category **cond-mat.dis-nn** (disordered systems / neural networks — the statistical-physics-of-Hopfield-networks category). "Preprint."

**Field / genre:** Theory of energy-based associative memory in Krotov's modular "HAMUX" framework ([15] Krotov 2021 hierarchical AM; [16] Krotov, Hoover, Ram, Pham 2025 "Modern methods in associative memory"), plus synthetic simulations, plus a mechanistic-interpretability probe of Llama-3-8B. It is **theory + simulation + LLM probing. Nothing is trained.** Every weight is hand-set (stored patterns, a Gram-matrix competition matrix, an identity projection). There is no sequence, no plasticity rule, and no learning signal anywhere in the paper.

**One-sentence summary of the mechanism:** a Modern-Hopfield (softmax) retrieval over N stored patterns gets an *additive per-memory logit bias* λ·s_μ from a "gate" layer with one neuron per stored memory; the gate is driven by an external context vector, by an anti-Hebbian-looking competition between gates of similar memories, and by positive feedback from the retrieval distribution itself (gain λ). The fixed point is p* = softmax_β(b + λA^{-1}u + λ²A^{-1}p*), unique when βλ²/(2η_min) < 1.

Page numbers below refer to the paper's own page numbers (as printed at the page breaks in the extracted text). Where I infer something that the paper does not say, I mark it **[inference]**.

## 1. What the paper actually does

### 1.1 Architecture (§3.1, pp.2–4; Figure 1 p.3)

Four neuron layers (p.3, §3.1.1), quoting:

> "The context (c ∈ R^{d_c}) receives external input specifying task or behavioral state, the gates (s ∈ R^N) which contain one neuron per stored memory and selectively activate a sparse subset based on context, and the query (q ∈ R^{d_q}) layer, which receives the noisy input for retrieval."

Context, gate and query layers use the quadratic Lagrangian L(x) = ½‖x‖², so activations are the identity: ĉ = c, ŝ = s, q̂ = q. The retrieval layer r ∈ R^N uses the LogSumExp Lagrangian

    L_r(r) = (1/β) log Σ_{i=1}^N exp(β r_i),      r̂_i = exp(β r_i) / Σ_j exp(β r_j),

so r̂ is a distribution over the N stored memories.

Four "hypersynapses" (energy terms), §3.1.2, p.3 — copied exactly:

(i) Context–gate alignment: **E_{h1} = −ŝ^⊤ W_{h1} ĉ**, W_{h1} ∈ R^{N×d_c}. Currents: I_s^{(h1)} = W_{h1} ĉ ("context drives gates") and I_c^{(h1)} = W_{h1}^⊤ ŝ ("gates feed back to context").

(ii) Sparsity-inducing self-synapse ("the crux of our construction"): **E_{{h2}} = (α/2) ŝ^⊤ W_{h2} ŝ**, with (W_{h2})_{ij} = ⟨ζ^i, ζ^j⟩ for i ≠ j and zero diagonal, α ≥ 0 the penalization strength. "This produces a competitive signal I_s^{(h2)} = −2αW_{h2}ŝ that suppresses gates whose memories are close to already-active ones, enforcing sparse gate patterns without explicit regularization." (Note: the "−2α" is inconsistent with Eq. (2) below, which uses α; the gradient of (α/2)ŝ^⊤W_{h2}ŝ for symmetric W_{h2} is αW_{h2}ŝ, so Eq. (2) is the correct one and "2α" is a typo **[inference]**.)

(iii) Cross-circuit coupling: **E_{h3} = −λ ŝ^⊤ r̂**, λ > 0, identity-weighted. "The bidirectional signals I_s^{(h3)} = λr̂ and I_r^{(h3)} = λŝ allow context-derived gate activations to bias retrieval while retrieval outcomes refine the gates. Large λ forces tight coordination between subcircuits, while small λ permits near-independent operation. When the context signal has a larger magnitude, its influence on retrieval dominates the reverse direction." (p.3)

(iv) Memory retrieval: **E_{h4} = −q̂^⊤ W_{h4} r̂**, W_{h4} = [ζ^1, …, ζ^N] ∈ R^{d_q×N} (the stored patterns as columns). I_q^{(h4)} = Σ_μ ζ^μ r̂_μ (a softmax-weighted combination of memories, i.e. the MHN update); I_r^{(h4)} = W_{h4}^⊤ q̂ (query–memory similarities).

So the memory is a **dense/modern Hopfield (softmax) memory with a static pattern matrix**, auto-associative (the query relaxes toward a combination of the same stored patterns). It is not an outer-product/Hebbian weight matrix and it is never written to.

### 1.2 Dynamics (§3.1.3, p.4, Eqs. 1–4) — copied exactly

    τ_c ċ_i = (W_{h1}^⊤ ŝ)_i − c_i                                              (1)
    τ_s ṡ_i = (W_{h1} ĉ)_i − α Σ_{j≠i} ⟨ζ^i, ζ^j⟩ ŝ_j + λ r̂_i − s_i              (2)
    τ_r ṙ_μ = λ ŝ_μ + ⟨ζ^μ, q̂⟩ − r_μ                                            (3)
    τ_q q̇_i = Σ_μ ζ_i^μ r̂_μ − q_i                                              (4)

> "Equation (3) reveals the two-stage mechanism: the pre-softmax score for memory µ decomposes as a context-driven gate bias λŝµ and a query-memory similarity ⟨ζµ, q̂⟩, with the gate bias able to reshape the retrieval landscape before the query has fully resolved. When the context subcircuit operates at a faster timescale (τc, τs ≪ τr, τq), the gates effectively precondition retrieval dynamics." (p.4)

Important reading note: in **all** theorems the context and query layers are effectively clamped — the theorems take u := W_{h1}c and b_μ := ⟨ζ^μ, q⟩ as fixed inputs and analyse only the (s, r) "coupled gate-retrieval subsystem". Eq. (1) (context relaxes toward W_{h1}^⊤ŝ, i.e. toward the context implied by the active gates) and Eq. (4) (query relaxes toward the retrieved pattern) are written down but never analysed **[inference from what is/isn't in §3.2 and App. C]**.

The dynamics are gradient descent on the total energy (App. A.1.2, Eq. 9: τ_ℓ dx_ℓ/dt = −∂E_total/∂x̂_ℓ = I_{x_ℓ} − x_ℓ) and Theorem A.3 (p.14) gives energy descent dE/dt ≤ 0, with "Strictly positive definite Hessian ⇒ converges to fixed point" — **if energy is bounded below**. **[inference]** The h2 energy plus the gate neuron energy is ½ s^⊤A(α)s with A(α) = (1−α)I + αG, which is bounded below only when A(α) ⪰ 0 (the "subcritical" regime). In the supercritical regime the gate state diverges exponentially (Eq. 39 below); the paper's "winner-take-all" is a runaway, not a bounded attractor, and the authors handle it numerically by stopping at a finite horizon (App. D.2, p.23). The limitations section is candid: "our current analysis does not fully characterize the continuous-time trajectory of the system, meaning we lack strict mathematical guarantees of convergence from arbitrary initializations." (p.9)

### 1.3 Theorem 3.1 — separation gap (p.4; proof App. C.1, pp.15–16)

Definitions (p.4): ∆_raw := ⟨ζ^μ, q⟩ − max_{ν≠μ} ⟨ζ^ν, q⟩ (raw similarity gap), ∆_gate := s_μ − max_{ν≠μ} s_ν (gate contrast), ∆ := ∆_raw + λ∆_gate (effective separation gap).

> **Theorem 3.1.** The target pattern µ is a stable fixed point of the retrieval dynamics with retrieval probability P(µ) ≥ 1 − ϵ if
>     ∆ = ∆_raw + λ ∆_gate ≥ (1/β) ln( (1 − ϵ)(N − 1) / ϵ ).
> In particular, when ∆_gate > 0, increasing λ increases ∆ and relaxes the required raw separation.

Proof (C.1): S(μ,q) := ⟨ζ^μ, q⟩ + λs_μ (19); at the retrieval fixed point r*_k = S(k,q); P(μ) = e^{βS(μ,q)}/Σ_k e^{βS(k,q)} (20) ≥ 1/(1 + (M−1)e^{−β∆}) (22) (M = N). Corollary 3.2 (informal, from Ramsauer et al. [29] Theorems 4–5, restated as B.1/B.2 p.15): larger separation ⇒ exponentially better one-step retrieval and exponentially smaller retrieval error. Sanity check: with N = 50, β = 3.5, ε = 0.05 the threshold is (1/3.5)·ln(931) ≈ 1.95, matching the "Exact threshold (ε=0.05): 1.95" printed in Fig. 2(c).

### 1.4 Theorem 3.3 / C.1 — gate-only phase transition (p.5; formal version pp.16–18)

Setting: λ = 0 (no retrieval feedback), uniform context input u = p·1 ("so the context does not distinguish between memories"). Fixed point A(α)s* = u with

    A(α) ≜ I + αW_{h2} = (1 − α)I + αG,    G_ij = ⟨ζ^i, ζ^j⟩,  rank(G) = min(N, d) =: R.

Spectral decomposition G = Σ_{k=1}^R μ_k v_k v_k^⊤, extended to an orthonormal basis of R^N with μ_k = 0 on ker(G); μ_min, V_min, P_min as the smallest eigenvalue, its eigenspace and projector. A(α)v_k = η_k(α)v_k with **η_k(α) = 1 − α(1 − μ_k)** (31), η_min(α) = 1 − α(1 − μ_min) (32), **α_crit := 1/(1 − μ_min)** (33).

(i) Subcritical (α < α_crit): A(α) ≻ 0, unique fixed point **s* = A(α)^{-1}u = Σ_{k=1}^N (c_k/η_k(α)) v_k, p* = softmax(βs*)** (34) (the main-text version of this formula at p.5 is garbled in the extraction; this is the App. C version). Modes in V_min amplified by 1/η_min(α) → ∞ as α → α_crit.

(ii) Supercritical (α > α_crit): modal dynamics τ_s ȧ_k = c_k − η_k(α)a_k (36), a_k(t) = c_k/η_k(α) + (a_k(0) − c_k/η_k(α))e^{−η_k(α)t/τ_s} (37); with γ_min(α) := −η_min(α) = α(1 − μ_min) − 1 > 0 (38), the critical modes grow as **a_k(t) = −c_k/γ_min(α) + w_k e^{γ_min(α)t/τ_s}, w_k := a_k(0) + c_k/γ_min(α)** (39). Define ξ := P_min w, i* := argmax_i ξ_i (assumed unique). Then p(t) → δ_{i,i*}, and p_{i*}(t) ≥ 1 − δ by time

    t*(α) = (τ_s/γ_min(α)) [ ln( κ/(β∆_ξ) ) + O(1) ],   ∆_ξ := ξ_{i*} − max_{j≠i*} ξ_j > 0.   (47)

> "The key insight is that the selected index i∗ is governed by (a) the geometry of the memory interactions through the eigenspace Vmin of G corresponding to µmin, and (b) the initialization/input bias w.r.t. the space of stored memories." (p.5)
> "When N > d, µmin = 0 and γmin(α) = α − 1, while Pmin is the projector onto ker(G), so the winner is determined by the projection of w onto ker(G)." (p.18)

i.e. when there are more memories than dimensions (as in every simulation here, N = 50 > d = 10, so α_crit = 1 exactly), the WTA winner is decided by the component of (initial gate state + input) lying in the **null space of the memory Gram matrix** — a direction carrying no content information **[my gloss]**.

### 1.5 Theorem 3.4 / C.3 — self-consistent retrieval with feedback (p.5; proof pp.20–21)

> **Theorem 3.4 (Self-consistent Retrieval).** Let u := W_{h1}c and b = (b_1, …, b_N)^⊤, where b_µ := ⟨ζ^µ, q⟩. Assume A(α) > 0 and define η_min(α) := λ_min(A(α)). For any λ > 0, every fixed point (s*, r*) of the coupled gate-retrieval subsystem satisfies,
>     s* = A(α)^{-1}(u + λp*),    r* = b + λA(α)^{-1}u + λ²A(α)^{-1}p*,          (5)
> where p* = softmax_β(r*). Equivalently, p* is a fixed point of the self-consistent map,
>     p* = Φ_{α,λ}(p*) := softmax_β( b + λA(α)^{-1}u + λ²A(α)^{-1}p* )            (6)
> Conversely, any fixed point p* = Φ_{α,λ}(p*) induces a fixed point (s*, r*) through (5). Furthermore, if βλ²/(2η_min(α)) < 1, the subsystem has a unique fixed point.

Decomposition (p.5): r* = b [query evidence] + λA(α)^{-1}u [context-filtered bias] + λ²A(α)^{-1}p* [retrieval-gate feedback]. Proof: Lemma C.4 ‖diag(p) − pp^⊤‖_2 ≤ ½ (Popoviciu), so the softmax Jacobian has ‖D‖_2 ≤ β/2; B_{α,λ} = λ²A(α)^{-1} has norm λ²/η_min(α); Lipschitz constant βλ²/(2η_min(α)); Banach on the simplex.

> "The condition βλ²/(2η_min(α)) < 1 also has a natural interpretation. The quantity η_min(α) measures the stability margin of the gate subsystem. As α → α_crit, this margin shrinks, so even small values of λ can substantially affect retrieval. Thus, context coupling becomes more influential near the gate critical regime. … below the contraction threshold, context smoothly biases retrieval, whereas beyond it, retrieval-gate feedback can bias selection or winner-take-all behavior." (p.5)

### 1.6 Theorem C.2 — criticality with feedback (App. C.3, pp.18–19; only "preliminary" per p.6)

Assumptions: λ > 0, τ_s ≪ τ_r so s* = A(α)^{-1}(u + λr̂) on the fast timescale; uniform context u = u_0·1; uninformative query ⟨ζ^μ, q̂⟩ = q_0 ∀μ; G·1 = μ_G·1; μ^⊥_min = smallest eigenvalue of G on 1^⊥; α_crit := (1 − μ^⊥_min)^{-1}. Slow dynamics (49): τ_r ṙ = λA(α)^{-1}u + λ²A(α)^{-1}r̂ + q_0·1 − r. Jacobian at the uniform state (50): J_sys = (λ²β/N)A(α)^{-1}P_⊥ − I, eigenvalues λ²β/(Nη_k(α)) − 1 (53). Result (reconstructed from the garbled display at p.18, consistent with the derivation at p.19):

    α^λ_crit = α_crit · (1 − λ²β/N),      valid when λ²β < N.

> "In particular, for α^λ_crit < α < α_crit, the gate subsystem alone is subcritical (its uniform state is stable), and it is the retrieval feedback loop through the softmax nonlinearity that destabilizes the uniform state, inducing winner-take-all retrieval." (p.18)
> "when λ²β ≥ N, the feedback gain is strong enough that the uniform state is unstable for all α > 0." (p.19)

And on p.6: "As λ increases the empirical α_crit shifts to smaller values. While this agrees with our preliminary results in Appendix C.3, we emphasize that our theoretical threshold does not match the empirical threshold."

### 1.7 Simulations (§3.3 pp.5–6; App. D pp.22–23). All on 1 H100.

- **D.1 (Fig. 2, separation):** N = 50 unit-norm memories in R^{10}, ζ^μ ~ N(0, I_d) normalised; β = 3.5; α = 0.1; **query q = ζ^μ + σ_q ε, context c = ζ^μ + σ_c η with σ_c = 0.3** (the context is a *less noisy copy of the target memory*); σ_q over 12 levels in [0, 3]; λ ∈ {0, 1, 2, 4, 8, 16}; 6000 trials per (σ_q, λ). Accuracy = fraction with argmax_ν r̂_ν = μ. Result: "The accuracy is non-decreasing in λ, with the largest gains in the intermediate noise regime. Context does not eliminate error at extreme noise, but it substantially extends the operational noise range." All (∆, r̂_μ) points lie on/above the bound 1/(1 + (N−1)e^{−β∆}). No accuracy numbers are given in text; only curves. (W_{h1} is not stated in D.1; by §4.1 it is presumably W_{h1} = Z^⊤ so u_μ = ⟨ζ^μ, c⟩ **[inference]**.)

### 1.8 Transformer part (§4, pp.6–8; App. D.4–D.5, pp.23–26)

Mapping (§4.1, p.7): memories ζ^μ = rows of the unembedding W_U ∈ R^{N×d}; gate W_{h1} = Z^⊤P with Z = W_U, P ∈ R^{d×d_c}, so s_μ = ⟨ζ^μ, Pc⟩; **P = I** ("Learning P ≠ I is an important direction that we defer to future work."). Context = function-vector-style mean difference, averaged over n queries:

    c̄^{(ℓ)} = (1/n) Σ_{i=1}^n ( h^{(ℓ)}_{ICL,i} − h^{(ℓ)}_{zero,i} ),

"which removes any query-specific information to yield a shared task-level signal." Query q_i = h^{(ℓ)}_{zero,i}. Score:

    r_μ = ⟨ζ^μ, q_i⟩ + λ⟨ζ^μ, c̄^{(ℓ)}⟩.                                            (7)

Two simplifications (Remark, p.7): α = 0 (A = I) because "the heavily skewed spectrum of actual LLM unembedding matrices makes the stable α regime practically degenerate" and "native transformer dynamics directly induce this geometric sparsification"; and the λ² term is dropped "because transformers lack single-layer recurrence". **[inference]** With P = I and α = 0, Eq. (7) is literally r = W_U(h_zero + λc̄): the entire LLM experiment is "add λ × a task vector to the zero-shot hidden state and decode".

Results: Llama-3-8B (32 layers); SST-2 (K = 2), AG-News (K = 4), TREC (K = 6), LAMA P36 "capital-of". (i) Decoding h^{(ℓ)} through W_U: zero-shot stays broadly distributed; with demonstrations N_eff collapses onto the label set at later layers (Fig. 4, 8, 9). (ii) Additive score: "up to ∼86% accuracy, successfully capturing the vast majority of the predictive power of full ICL (∼95%)" on SST-2 (Fig. 5; context layers 20/24/28/32, query layer 32, λ swept 10^{-2}–10^{1}); AG-News/TREC "much lower" absolute accuracies (axes top out ≈0.5 and ≈0.4) but the same trend, and "context vectors extracted from the later half of the network (ℓ ≥ 20) carry sufficient structural information" (p.25). (iii) LAMA: positive c̄₊ (correct pairs) vs negative c̄₋ (wrong pairs), λ ∈ {1.0, 1.5, 2.0}, context layer swept 0–32: "injecting supportive context deepens the target's energy minima (sharpening retrieval), while adversarial context actively shifts the distribution mass toward competing attractors" (p.8). (iv) D.4 replicates [37]: linear-probe separability peaks early-to-mid layers; cosine alignment with the unembedding sharpens only in final layers (Fig. 7).

**Training details that matter:** none — nothing is trained. Hyperparameters that matter: β (3.5 / 5.0), α (0.1 subcritical for retrieval; swept 0–2 for the transition), λ (0–16), σ_c = 0.3, σ_init = 10^{-4}, 500 fixed-point iterations.

## A. Direct answers to the paper-specific questions

**Authors / field / theory vs simulation.** See header. Physics-of-Hopfield + ML interpretability; theory (4 theorems with proofs), small synthetic simulations (N = 50, d = 10), and LLM probing. No training.

**Model equations.** §1.1–1.6 above, copied. Fixed-point formulation: yes, Eq. (5)–(6) and the iteration in D.3. Convergence: energy descent (Theorem A.3) in the bounded regime; Banach contraction for the self-consistent map when βλ²/(2η_min(α)) < 1; exponential WTA runaway when α > α_crit (time constant τ_s/γ_min(α)); no guarantee from arbitrary initial conditions (p.9); future work proposes an entropy-maximisation / mirror-descent / deterministic-annealing analysis (pp.9–10).

**Where does the context come from?** **Given externally, in every part of the paper.** Theory: c is an input layer "specifying task or behavioral state", clamped in all proofs (u = W_{h1}c fixed). Simulation: c = ζ^μ + 0.3η, i.e. a noisy copy of the *target memory itself* — so ∆_gate > 0 is essentially guaranteed by construction, and Fig. 2 shows that a cleaner second cue helps a noisier first cue. LLM: c̄^{(ℓ)} is extracted from the model's own residual stream as the mean demonstration effect, averaged over queries. It is **never inferred from the retrieved pattern** in any analysed result. The *only* channel by which retrieval informs the gate is the λr̂ feedback term in Eq. (2), and the gate in turn could inform the context layer via Eq. (1) (τ_c ċ = W_{h1}^⊤ŝ − c), but Eq. (1) is never analysed or simulated **[inference]**. Robustness results: only the σ_q sweep (σ_c fixed) and 1-shot vs 4-shot / positive vs negative contexts in the LLM. No ambiguity, mixed-cue, or capacity experiments.

**Capacity.** None quantitative. The paper only inherits MHN exponential capacity by citation (Corollary 3.2; App. B). No patterns-per-context, no inter-context interference, no comparison to 0.14N. The only "phase diagram" is gate selectivity vs (α, λ): α^λ_crit = α_crit(1 − λ²β/N) (Theorem C.2), about WTA vs uniform gating, not storage.

**Same cue → different memories in different contexts?** Not treated as a storage problem (there is one memory bank and one context). The paper's only statements that touch it: the motivation "the same query elicits drastically different behaviors based on the system prompt ([23])" (p.1); the mechanism "when ∆_gate > 0, increasing λ increases ∆ and relaxes the required raw separation" and "including the right context c can directly increase the separation gap between memories through its action on s" (p.4); the LAMA experiment where the *same* fixed query is steered to the target by c̄₊ and toward "competing attractors" by c̄₋ (p.8, Fig. 6); the related-work pointer that "[28] introduced context-modular networks that partition binary memories across contexts" (p.2); and the limitation that "analyzing how behavioral system prompts or persona adoption (e.g., 'act as a liar') continuously reshape the energy landscape over long horizons" is future work (p.10). **[inference]** Theorem 3.1 does cover our case formally: store the N = P·S patterns ζ^{(i,s)} (one per key–stream pair); a query KEY_i has ∆_raw = 0 among the S same-key competitors, and the context must supply λ∆_gate ≥ (1/β) ln((1−ε)(N−1)/ε). The h2 competition term is proportional to ⟨ζ^i, ζ^j⟩, so same-key memories (which overlap most) are exactly the ones whose gates compete hardest — the construction pushes conflicting bindings into a WTA among themselves, with the context breaking the tie. But this is my reading, and the paper never stores conflicting patterns.

**Learning the gate?** Not discussed. W_{h1} hand-set (Z^⊤P, P = I); W_{h2} set from the Gram matrix of stored memories; no plasticity, no Hebbian or three-factor rule. The nearest things: (W_{h2})_{ij} = ⟨ζ^i, ζ^j⟩ *is* a correlation (Hebbian-form) matrix used with a negative sign — an anti-Hebbian competition between gate neurons whose memories overlap **[inference]**; and the biological framing that "astrocytes gate hebbian synaptic plasticity" [34] and "astrocytic networks structurally prime local synaptic landscapes, dictating neuronal responsiveness and plasticity" (p.2), which is motivation only. "Learning P ≠ I" and "learning a dedicated context-gate projection matrix" are explicitly deferred (pp.7, 10).

**Translation to our setting / two-pass scheme.** See §6 below. Short version: the paper concretely supports (a) a gate that is an additive-in-logit (⇒ multiplicative-in-weight) bias on the memory read, (b) a fast gate / slow memory timescale split, (c) gate = stable linear filter of (context drive + λ × current retrieval distribution), iterated to a fixed point with a sharp uniqueness condition, and (d) a warning that the feedback term alone breaks symmetry arbitrarily. It does **not** support routing by prediction error, learning the router, or carrying context over a sequence.

## 3. Relevance to BDH-CQ reconstruction

**Memory update rule — no match.** Pathway: S_t = U_θ(S_{t−1}, D_t), linear attention as S_t = S_{t−1} + U_θ(D_t), "linear correction rules on S". This paper's memory W_{h4} = [ζ^1 … ζ^N] is static and never written; there is no sequence and no update rule of any kind. Nothing here constrains U_θ.

**Latent reasoning loop — a real structural match, worth noting.** Pathway: H_0 = E_θ(x*, S_K), H_{r+1} = F_θ(H_r, S_K), ŷ = G_θ(H_R). This paper's D.3 iteration is exactly of that form:

    r^{(k+1)} = λA(α)^{-1}u + λ²A(α)^{-1} softmax(β r^{(k)})     (general case: + b, Eq. 6)

with H ↔ r (pre-softmax logits over memory slots) or p = softmax(βr); S_K ↔ the fixed memory entering through b = Z^⊤q (query–memory similarity), A(α)^{-1} (built from the memory Gram matrix) and the softmax over memory indices; F_θ ↔ Φ_{α,λ}; G_θ ↔ argmax of p*; E_θ ↔ r^{(0)} (b + λA^{-1}u in the theory; near-zero noise in D.3). The paper supplies what a reconstruction would want from such a loop: a **convergence condition** (contraction iff βλ²/(2η_min(α)) < 1), a **failure mode** when it is violated (feedback-driven WTA whose winner depends on initialisation — Theorem C.2 and the discussion at p.5), a **budget** (up to 500 iterations to 10^{-8}), and the explicit remark that a feed-forward transformer *cannot* implement the λ² term "because transformers lack single-layer recurrence" (p.7) — i.e. a model with a latent recurrence over a fixed memory is precisely what is needed to realise the second-order retrieval→gate→retrieval feedback.

**What does not match:** F_θ here is hand-set, not learned; the latent lives in memory-index space (N slots), whereas BDH-CQ's H presumably lives in neuron space; the memory is a softmax (dense Hopfield) read, not a linear-attention read; BDH-CQ's K-step memory build-up has no counterpart. **[inference]** The most defensible takeaway for the reconstruction: "F_θ(H_r, S_K) = read S_K with a query that includes a feedback term from H_r, pass through a (soft) normalisation, repeat" has a clean, analysable instance here with a known stability margin; the λ² (feedback gain) × β (sharpness) / stability-margin product is the knob that separates smooth refinement from collapse. Confidence that this is what Pathway does: low; confidence that it is a plausible analysable template: moderate.

## 4. Relevance to distant context cues

**How is the context carried?** It isn't, by the paper's mechanism. In the theory the context is a separate clamped input layer, persistent for the whole retrieval episode (infinite persistence, no decay), and the gate is a *fast* function of it (τ_s ≪ τ_r). In the LLM experiments the demonstration information has already been transported to the query position's residual stream by the pretrained transformer's attention; the paper merely reads it out as the mean difference c̄^{(ℓ)} = (1/n)Σ(h_ICL − h_zero). The component doing the carrying is Llama-3's own attention; the paper does not model it.

**Given or inferred?** Given (external/clamped) in theory and simulation; in the LLM, derived from the residual stream but with query-specific information deliberately averaged out — a pooled, task-level vector computed offline from n queries, not something the model computes causally at run time.

**Time scale.** Gate fast, retrieval slow: τ_c, τ_s ≪ τ_r, τ_q (p.4). In the LLM mapping, "time" is depth: context processing ("separability … emerging in early-to-mid layers") precedes query resolution ("alignment … sharpening later") (p.6–7, App. D.4), and usable context vectors come from "the later half of the network (ℓ ≥ 20)" of 32 (p.25).

**How is that component trained?** Not trained (theory) / pretrained by language modelling (LLM). No label-free discovery of context is demonstrated anywhere.

**What it does say that bears on our header-layout problem [inference]:** (i) The context signal needed to steer retrieval is *additive and low-dimensional* — a single direction λc̄ added to the query suffices for ~86% of ICL on SST-2. In our model a one-token header, if copied into each position's residual by layer-1 attention, is exactly such an additive direction. (ii) The paper's diagnostic (App. D.4) is directly reusable: fit a logistic-regression probe for stream identity on our residual stream at each layer and each position of the block; wherever separability exists, a per-layer gate reading that layer can route. If separability is absent at the K/V positions, no gate design on top of that layer can work, and the problem is upstream (attention must copy the header first). (iii) The paper's success depends on context vectors from *late* layers; in our 3-layer model that argues for gating layers 2–3 from the residual after layer 1 or 2, not from raw embeddings — consistent with our "per-layer gate over the residual stream" plan and against the raw-embedding v_t used by both of our current gates.

## 5. Relevance to our gate — concrete, implementable

Notation for this section: channel ℓ ∈ {1..k} holds S^ℓ_{t} = Σ_{s≤t} g_s^ℓ · (outer product of x_s) · decay^{t−s}; our score is (x_t·x_s)(g_t·g_s)decay^{t−s}; no softmax.

**5.1 Our multiplicative gate is the right translation of the paper's additive gate.** The paper adds λs_μ to the *logit* of memory μ inside a softmax, which multiplies memory μ's retrieval weight by e^{βλs_μ}. **[inference]** If one instead concatenates/adds a context vector to the key in a *linear* (no-softmax) memory — the P = I, α = 0 recipe of Eq. (7) — the score becomes (x_t + λc_t)·(x_s + λc_s) = x_t·x_s + λ(x_t·c_s + c_t·x_s) + λ²c_t·c_s: the cross-stream interference term x_t·x_s survives at full weight, and the context only adds a same-stream bonus λ². In a softmax memory that bonus becomes a factor e^{βλ²}, which is why the additive recipe works for Llama but would not kill interference in our linear memory. Our (g_t·g_s) factor plays the role of e^{βλ(s_s)} — multiplicative suppression. This supports keeping the gate multiplicative on the score (as we do) rather than adding a context vector to the key.

**5.2 Theorem 3.1 as a margin target.** With N = P·S stored bindings and ∆_raw = 0 among the S same-key competitors, the paper's condition reads λ∆_gate ≥ (1/β) ln((1−ε)(N−1)/ε). **[inference]** In our terms, the gate contrast between the true stream's channel and the best other channel must exceed a margin that grows only logarithmically in the number of stored bindings — a hinge on "gate contrast" is the natural auxiliary loss, and it is the shape of our existing "early hinge penalty". The paper gives no learning rule, but it does give the target quantity (∆_gate) and its required size.

**5.3 Retrieval→gate feedback: what the paper supports and warns.** The fixed point s* = A(α)^{-1}(u + λp*) says the gate should be a *stable linear filter* of (context drive) + λ × (current retrieval distribution). A two-pass per-token scheme consistent with this **[our extrapolation of the paper's structure]**:

    pass 1 (probe read, every channel):   y_t^ℓ = S^ℓ_{t−1} x_t,   f_t^ℓ = some scalar read statistic (e.g. ‖y_t^ℓ‖, or x_t^⊤S^ℓ_{t−1}x_t)
    gate:                                  g_t = softmax( W_g h_t  +  λ·A^{-1} f_t )      (h_t = window / recurrent / residual features = the paper's u)
    pass 2 (gated read and write with g_t).

The paper supports iterating this to a fixed point with uniqueness iff βλ²/(2η_min) < 1 (β = our softmax temperature, η_min = the gate filter's smallest eigenvalue; with A = I, the condition is βλ² < 2) and warns that above it the loop performs WTA on its own, with the winner set by initial state and content geometry rather than by the task (Theorems 3.3(ii), C.2). The paper does **not** support routing by prediction error — nothing in it uses an error signal — nor does it analyse feedback across tokens (gate at t from the read at t−1); its loop is within a single retrieval episode. The LLM section explicitly drops the loop.

**5.4 A sign warning specific to conflicting bindings [inference].** The paper's feedback is *positive* (retrieved → gate up → retrieve more; "supportive context deepens the target's energy minima"). Transplanted naively as "write the token where its key is already known", a familiarity-driven gate would send all S values of the same key into the same channel — reinforcing exactly the key-splits we observe. For conflicting bindings, the useful run-time signal at a VAL position is *disagreement*: the channel where reading KEY returns something far from the incoming VAL is the channel to avoid, i.e. route by *error*, not familiarity. That is outside the paper (the nearest thing is the adversarial c̄₋ pushing mass "toward competing attractors", Fig. 6). Treat it as our hypothesis, not as something the paper backs.

**5.5 Competition proportional to content overlap (the h2 term).** (W_{h2})_{ij} = ⟨ζ^i, ζ^j⟩ with zero diagonal: gates of *similar* memories inhibit each other, which "enforces sparse gate patterns without explicit regularization" and has a sharp critical point α_crit = 1/(1 − μ_min). **[inference]** Channel-level analog: a k×k competition matrix C_t with (C_t)_{ℓm} = overlap of what channels ℓ and m currently store about x_t (e.g. ⟨S^ℓ_{t−1}x_t, S^m_{t−1}x_t⟩ normalised), zero diagonal, and gate logits z_t = W_g h_t − α C_t g_t solved quasi-statically (one or two Jacobi steps) — this penalises putting the current key into two channels that already hold overlapping content for it, which for conflicting bindings means pushing a key's second value *away* from the channel holding its first. Keep α below the critical value (A(α) ≻ 0) so that the gate remains a filter and the context decides; the paper says the useful regime is *near* criticality ("context coupling becomes more influential near the gate critical regime", p.5) because weak context drives are amplified by 1/η_min there. Caveat from the paper itself: with real representations the Gram spectrum is skewed and "the stable α regime [is] practically degenerate" (p.7); with N > d the smallest eigenvalue is exactly 0 and α_crit = 1.

**5.6 Which of our beliefs it supports / contradicts / warns about.**
- Supports: fast gate, slow memory (τ_s ≪ τ_r) — our per-token gate over a decaying memory has the same split. Supports: sparse, near-one-hot gates emerge from competition, and context should break the tie. Supports (weakly, via the LLM part): the context signal is an additive direction in the residual stream at mid-to-late depth → the per-layer residual gate.
- Contradicts nothing we have measured; but it gives no evidence that a gate can *discover* context without labels — all its gates are hand-set or read out of a pretrained model.
- Warns: (a) self-reinforcing gates (recurrence or retrieval feedback) go WTA from initialisation bias when the context is uninformative — the uniform state's instability threshold is α^λ_crit = α_crit(1 − λ²β/N), and for λ²β ≥ N it is unstable "for all α > 0"; **[inference]** this is a clean theoretical account of our position/key splits and of the recurrent gate's "expansive/unstable at eight streams" behaviour (supercritical runaway e^{γ_min t/τ_s} = exploding pre-softmax logits = saturated softmax). (b) The WTA winner with N > d is set by the projection onto ker(G) — a content-free direction — so unsupervised competitive gates latch onto whatever is most linearly salient (key identity, position), not onto the task-relevant stream. (c) Pooled summaries: the paper's c̄ is an offline average over n queries that "removes any query-specific information" — it works only because a pretrained transformer did the transport; our EMA/fading-memory gates (0/10) are the causal version of such pooling and the paper offers no reason to expect them to work on their own. (d) Theory–experiment mismatch for the critical threshold (p.6) — don't trust the α^λ_crit formula quantitatively. (e) No straight-through estimators or discrete routing anywhere; the paper's gates are continuous and quasi-static.

**5.7 Initialisation / training suggestions, as far as the paper allows.** The paper trains nothing, so these are extrapolations anchored to its constants: initialise any retrieval→gate feedback gain λ small enough that βλ²/(2η_min) ≪ 1 (e.g. β = 1 softmax, λ² < 0.5 with A = I) and anneal upward; initialise the fixed-point latent at zero/near-zero (σ_init = 10^{-4} in D.3) and iterate 1–3 steps per token; use the gate contrast ∆_gate as the quantity to monitor and, if any supervision is permitted, to hinge; keep competition α subcritical.

## 7. Verdict

This is a clean, small theory paper about a *given* context biasing a softmax Hopfield read, with a hand-built gate and no learning, so it does not move our central problem — label-free discovery of the stream partition — directly. What it does give us is (i) a precise statement of the quantity our gate must produce (a gate contrast ∆_gate exceeding a log-in-N margin, Theorem 3.1), (ii) a theory of why self-reinforcing gates collapse onto arbitrary, content-free splits when the context drive is weak (Theorems 3.3(ii), C.2 — winner set by initialisation and the null space of the content Gram matrix), with a quantitative stability condition βλ²/(2η_min) < 1 for any retrieval→gate feedback loop we might add, (iii) a sign warning that familiarity-based "route by what came back" would reinforce key splits for conflicting bindings, so any two-pass scheme should route by disagreement, which the paper does not cover, and (iv) support — via the Llama probing, not via the theory — for reading the gate from a mid-to-late residual stream rather than raw embeddings, together with a cheap diagnostic (per-layer linear probe for stream identity) to test whether the header information is even present where the gate looks. For BDH-CQ, the self-consistent map p* = softmax(b + λA^{-1}u + λ²A^{-1}p*) is a plausible analysable template for the latent refinement loop, with the explicit remark that feed-forward transformers cannot implement the λ² term; nothing here bears on the memory update rule. Next actions I'd take from this paper: run the layer-wise stream-identity probe on our residual stream (immediately), and read Podlaski–Agnes–Vogels PRX 2025 [28], which is where the context-partitioned memory with capacity claims actually lives. Confidence in this reading: high for what the paper contains (full text read, equations copied from the appendix versions); moderate for the translations in §5, which are mine.
