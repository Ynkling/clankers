# Multi-Channel Hebbian Plasticity in Multilayer BDH

> **Status (1 November 2026): concluded.** The author concluded the project on 1 November 2026. Revision 11 (final) is the report; [STATUS.md](STATUS.md) says what was found, what was left ready to run (the register test; S75b) and what was left open, and how to resume.

**Solves context-conditional binding by partitioning memory.** A window gate, slow memory and a targeted channel split find an eight-way partition without labels or restarts, on two machines with disjoint seeds; an independent clean-room replication agrees, and a referee has recomputed every number from the records.

This repository is a research fork of Pathway's [BDH (Dragon Hatchling)](https://github.com/pathwaycom/bdh). It extends BDH's Hebbian working memory with several memory channels and a gate that spreads each token's write over the channels and blends its read from them. The research sections below follow Revision 11 (final) of the project's technical report, *A Learned Partition of Working Memory on a Synthetic Binding Task with Local Cues*: the PDF is [`multichannel_hebbian_report_v11.pdf`](multichannel_hebbian_report_v11.pdf), with its LaTeX source alongside.
