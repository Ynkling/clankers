# Multi-Channel Hebbian Plasticity in Multilayer BDH

> **Status (21 October 2026).** Revision 10.2 is the current report, passed by the referee before its merge; [STATUS.md](STATUS.md) says where every thread stands and how to resume.

**Solves context-conditional binding by partitioning memory.** A window gate, slow memory and a targeted channel split find an eight-way partition without labels or restarts, on two machines with disjoint seeds; an independent clean-room replication agrees, and a referee has recomputed every number from the records.

This repository is a research fork of Pathway's [BDH (Dragon Hatchling)](https://github.com/pathwaycom/bdh). It extends BDH's Hebbian working memory with several memory channels and a gate that spreads each token's write over the channels and blends its read from them. The research sections below follow Revision 10 of the project's technical report, *A Learned Partition of Working Memory on a Synthetic Binding Task with Local Cues*: the PDF is [`multichannel_hebbian_report_v10.pdf`](multichannel_hebbian_report_v10.pdf), with its LaTeX source alongside.
